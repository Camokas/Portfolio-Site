# Security policy

## Reporting a vulnerability

Please do not publish security vulnerabilities, credentials, or private data in a public issue.

Use GitHub's private vulnerability reporting form instead: open the repository's **Security** tab, choose **Advisories**, and select **Report a vulnerability**. Include the affected page or file, clear reproduction steps, and the impact you observed.

## Supported version

Only the latest version deployed from the `master` branch is supported. Dependency and security updates are handled through automated GitHub checks and reviewed pull requests.
