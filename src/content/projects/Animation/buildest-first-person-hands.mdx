## Modelling and movement

I modelled and animated the hands in Blender, added noise to the animation curves, and refined the movement by hand before importing it into Unity.

<Video index={1} group open />

## Falling

The fall animation is connected to the player state. Values from the movement code adjust the timing so changes in physical speed can slightly change the animation pace.

<Video index={2} group open />

## Animator graph

I tuned the values sent to Animator for transitions between idle, movement, falling, and landing. This let the animations respond to movement without relying only on abrupt state switches.
